## 5. Brutalism and anti-design (now)
- **Concept:** raw digital punk. Reject the polished, conversion-tuned web template and show the structure and code of the page.
- **Feel:** underground, confrontational, glitchy, unpolished, very authentic.
- **Layout:** deliberately awkward. Visible table borders (thick, hard 1px black lines), overlapping or broken hierarchy, and huge type scaling. At AAA, the type may be huge but never clipped or forced into sideways scroll.
- **Texture:** screen static, pixelation, compression artefacts, raw concrete, and default browser styles (plain inputs, bright blue links).
- **Type:** monospaced coding faces (Courier, IBM Plex Mono) or unstyled default web fonts, blown up to fill the screen with no tracking adjustment.
- **Tone and copy:** blunt, dry, subversive. Reads like log files, error messages or a zine. No polite corporate service language.
- **Touchstones:** David Carson (Ray Gun), Balenciaga digital campaigns, early Craigslist-era HTML.
- **Prompt keywords:** web brutalism layout, digital punk zine, unstyled HTML layout, monospaced typography, raw concrete texture.
- **Rule:** make it deliberately raw. Prefer stark, confrontational layouts to smooth curves, elegant padding or pleasing animation.
