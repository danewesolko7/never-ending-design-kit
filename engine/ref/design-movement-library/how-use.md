## How to use it
1. Run inspiration-sweep C for the movement: look at its touchstones and current work online, and record the one technique each teaches.
2. Name the movement or blend, and list the rules you will apply from each.
3. Apply the precedence list above and note every rule you adapted.
4. Carry the movement through type, texture, colour and, when new copy is asked for, tone, on the chosen structure.
5. In the direction card and hand-off, say which rules came from which movement, with a touchstone for each.
