## 11. Modern CSS techniques (for rendering designs for review only)
Safe: `subgrid`, container queries, `:has()`, `text-wrap`, `aspect-ratio`, `clamp()`, `oklch()`, `color-mix()`, `mix-blend-mode`, `background-clip: text` (with fallbacks), `clip-path`, `shape-outside`, `writing-mode`.
