# Layout, graphic design and web design library

This is a pattern catalogue for structure: grids, primitives, page forms, openers, data-story patterns and anti-patterns. The fundamentals (hierarchy, Gestalt, grid, balance, typography, colour, usability) live in design-foundations; this library points there instead of restating them.

Read `rules/rules.md` first. The owner's standing rules override anything here. Patterns marked [2-COL] put text side by side and are banned while the no-side-by-side-text rule stands.

**Where this fits.** S3 uses this library for the three concepts, which are greeked roughs (greeked-structure); S6 uses sections 6 and 7 again for the comp. Its companions: inspiration-sweep B, greeked-structure, design-foundations and design-review (S3); inspiration-sweep C, design-movement-library and graphic-art-direction (S4); craft-pass (S6 and S8). Roughs use content.json word counts; the final copy arrives at S5, written into pages/*.json.

**Quality bar.** Earlier projects' work is not the bar: using it as the bar is how one past project ended up copying its predecessor. The bar is the owner's latest approved work on the current project, plus this test: blur the page and it should read as its own subject, with a clear hierarchy.
