## The pre-build gate (nothing is designed until every box is ticked)
Write this checklist into the working notes and tick each line with what was found. Show the completed gate to the owner.

- [ ] **Rules** read: `rules/rules.md`.
- [ ] **Reference library and registry** read: `ref/library.md`, `studio/library.md` and the studio registry (`studio/registry/fingerprints.jsonl`, checked by `tools/uniq.py`).
- [ ] **Content outline** in hand from S2, with word counts per element and the reader-first content-form-map table.
- [ ] **Visual discovery** from S1 in hand (the subject's artefacts), and each section's explanation job from S2.
- [ ] **Facts verified** against the most primary source; conflicts labelled; derived numbers recomputed.
- [ ] **Structure sweep** done where the library lacks references (inspiration-sweep B), at least two from outside web design.
- [ ] **Library check**: one line for each section of this catalogue used, saying what was chosen from it.
- [ ] **Three concepts**, each a different page form with one greeked rough (greeked-structure), naming its patterns and borrowed techniques.
- [ ] **Hierarchy map** for each layout (section 6).
- [ ] **uniq.py passes** for every concept fingerprint (no repeat of a past project in the registry).
- [ ] **Choice justified** by a fact about the content.

If any box is empty, go back.
