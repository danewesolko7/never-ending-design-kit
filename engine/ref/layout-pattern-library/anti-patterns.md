## 15. Anti-pattern catalogue
- **Layout**: identical card grids, bento grids, nested cards, a hero metric with a tiny label, large display numbers in a left column, numbered labels without a sequence, monotonous spacing, label|value rows, a split hero, every section the same template with the text moved left or right.
- **Type**: eyebrows, badges above headlines, flat hierarchy, too many near-identical sizes, one weight everywhere, crushed tracking, overused fonts (Inter, DM Sans, Space Grotesk, Playfair, Bebas), default italic serif display, arrows appended to links.
- **Colour**: cream grounds, near-black with a neon accent, gradient text, glows, glassmorphism.
- **Detail**: decorative grid backgrounds, side-stripe accents, a hairline border plus a wide shadow, extreme radii.
- **Motion**: fade-up everywhere, pulsing dots, marquees, bouncy easing, load animations added by habit.
- **Copy**: generic claims, em-dash overuse, slogan contrasts.
- **Repeats**: any move from the Signature registry beyond the one named reuse.
