## 14. Look at what you designed
1. Render in the kit (scratch HTML, never a deliverable) with the real fonts installed from fontsource (`tools/fontcheck.py` must pass). Greeked studies render with `tools/greek.py`.
2. Look at the page as a contact sheet (`node tools/shot.js` for page shots, then `python3 tools/contact.py`). Open one page's shot only to read it closely, and a crop only for a named fault.
3. Check hierarchy (the squint test on the page shot), rhythm, alignment, overflow, phone gutters, layering and contrast on coloured blocks.
4. Fix and repeat, then run design-review (measure, visual tests, foundations, usability, AAA) and frame it for the gate with milestone.py.
