# Technique library (starter)

The kit's starting library of reusable techniques: one technique per row, in plain words, with the public source where it
was seen. It ships with the engine so the first build has a wall of references before any sweep. A studio adds its own
rows and marks in `studio/library.md` (same section numbers); this file changes only at an approved G10.

**How to use it**
- Read only the sections your stage prompt names, here and in `studio/library.md`: page forms and grid at structure;
  type, colour, image, texture and motion at direction; proof, conversion and data at copy, comp and pages.
- Then sweep the web for what both files lack (`tools/refs.py --gaps` lists the thin sections), and record each new
  reference in the project's `references.jsonl`.
- Borrow the technique, never the layout, brand or image it came from.
- When the CD says "generic", "plain" or "template", pick from sections not used on the last project, and sweep before
  changing anything.

## 1. Page forms: what the whole page is
Take the page form from something the subject makes for itself.

## 12. Avoid (learned from builds and reviews)
- Card grids, label/value rows, logo walls, testimonial carousels, stat strips, numbered step cards, certificate badges.
- Tabs, maps or any novel device used as the site's navigation: a conversion risk.
- Split heroes and centred photo heroes; a long client list on the home page; lists of names at display size.
- Stepped markers that float alone or vary in width: they read as mistakes.
- Stacked rules, closing rules under lists, a fact repeated in the sentence under it.
- Extreme everywhere with no grid to push against; gimmicks offered as an answer to "generic".
- A concept used as literal page structure until it is lost.
- Text on photos or across band edges; double shadows; more than one treatment per photo set.
- Stock photos showing other companies' logos, number plates or the wrong country's streets.
- Stock "cyber" imagery: hooded figures, code rain, padlocks on circuit boards, glowing globes.
- Invented reviews, frequencies, rebates or accuracy claims ("100% accurate", "zero false positives").
- AI-default patterns: see the Impeccable slop catalogue (impeccable.style/slop).
