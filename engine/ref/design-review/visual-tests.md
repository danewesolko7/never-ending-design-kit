## 2. Visual tests (every view, 1440 and 390)
- **Squint:** blurred, one entry point, then a clear second level.
- **Mirror:** flipped horizontally, does it still hold? If not, the balance relies on chance.
- **Greyscale:** balance and hierarchy hold without colour.
- **Distance:** at 10% size it reads as a composed poster, not scatter.
- **Eye path:** the reading order (Z for poster screens, F for text) never doubles back or jumps a loud move.
- **Cut test:** cover the loud move. If the screen falls apart, the grid is not carrying the structure; if it improves, cut the move.
- **Skeleton:** blur all content. If the page still reads as a stock template, redesign the page form.
