## Tool
`python3 tools/greek.py structure-<n>.json --name c<n>`: the spec format is in `greek.py --help`. It draws the 12-column grid like a layout pad, image blocks with crossed diagonals, text as squiggles sized from word counts, figure boxes, large figures, rules, tint and dark grounds, and screen marks every 900px (844 on a phone), then renders at 1440, 390 and 320. It warns about text overlapping text or images, and about blocks running past their section. Measure with `python3 tools/pass.py --rough`; frame the three roughs for the CD with `python3 tools/milestone.py G3a`.
