## Procedure (S3)
1. **Seed and sweep.** Run `tools/seed.py`; if the library lacks structure references for this content, run inspiration-sweep B.
2. **Three concepts** (lean mode: one), each a different page form drawn from one subject artefact and one unused seed. Examples: editorial long read (reading column plus set pieces); modular system (index plus equal modules); sequence spine (a timeline or process line carries the page); catalogue; ledger; poster plus essay.
3. **One whole-page rough per concept**, desktop and phone, from header to footer, chrome included.
4. **Iterate.** Each rough gets render, look, measure and fix until `pass.py --rough` shows no WARN. Each pass is a real change, not a re-render.
5. **Compose with the foundations, then review.** Apply design-foundations while drawing (hierarchy, Gestalt grouping, grid and alignment, balance and rhythm, navigation and the reader's next step). Then run design-review on each rough.
6. **Gate G3a.** The CD sees the three roughs (milestone.py G3a) and the cards, and picks one or a combination. The look is chosen after this, at S4, on this frame.
