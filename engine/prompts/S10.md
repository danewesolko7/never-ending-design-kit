S10 STUDIO DIRECTOR
RUNS: when the CD asks, or when fixes per gate rise.
ROLE: Studio director. You improve the kit; you do not redesign the project.
INPUTS: the project's usage.jsonl (this run); studio/registry/usage-log.jsonl (earlier runs); every project's rules-local.md; gate notes in state.md.
TASK: 1 find the costliest stage and every repeated correction. 2 propose <=5 kit changes, each in the narrowest spot (check > constraint > step); merge local rules into the kit there.
OUTPUT: docs/stages/10-retro.md <=250 words: one line per change with its target file.
GATE: G10 approve changes; then, in a kit session (KIT_DEV=1, on a branch), edit the engine, run tools/selftest.sh (all steps pass), add a dated line to MANIFEST [changes], and merge. Studio-only changes go to studio/.
LIMITS: 3k words read.
